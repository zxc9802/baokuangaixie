# Next.js Initialization Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Initialize a verified Next.js application in `D:\视频脚本写作` with TypeScript, App Router, Tailwind CSS, ESLint, npm, and a `src/` directory.

**Architecture:** Use the official `create-next-app` CLI to generate the application in a temporary ASCII-named child directory because the target directory's Chinese name is not a valid npm package name. Generate without a nested Git repository, move the generated files into the existing repository root, and set a valid package name.

**Tech Stack:** Next.js, React, TypeScript, Tailwind CSS, ESLint, npm

- [ ] **Step 1: Revalidate source and destination before moving files**

Run:

```powershell
$projectRoot = (Resolve-Path -LiteralPath '.').Path
$stagingPath = (Resolve-Path -LiteralPath '.\nextjs-scaffold-temp').Path
if ($stagingPath -ne (Join-Path $projectRoot 'nextjs-scaffold-temp')) { throw "Unexpected staging path: $stagingPath" }
if (-not $stagingPath.StartsWith($projectRoot + [IO.Path]::DirectorySeparatorChar)) { throw "Staging path is outside project root" }
Write-Output "Validated $stagingPath -> $projectRoot"
```

Expected: the command prints the validated move from the staging directory to the repository root.

- [ ] **Step 2: Move generated files and remove the empty staging directory**

Run:

```powershell
$projectRoot = (Resolve-Path -LiteralPath '.').Path
$stagingPath = (Resolve-Path -LiteralPath '.\nextjs-scaffold-temp').Path

Remove-Item -LiteralPath $stagingPath
```

Expected: `package.json`, `src/`, and `public/` are in `D:\视频脚本写作`; `nextjs-scaffold-temp` no longer exists.
