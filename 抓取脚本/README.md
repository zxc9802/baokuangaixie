# 视频脚本助手 · 抖音采集桥

这是项目线上部署时由最终用户安装的 Chrome Manifest V3 扩展。它负责使用用户自己的抖音登录态搜索视频、读取发布时间及临时媒体地址，再把结构化结果交给项目后端。视频下载、压缩和 AI 分析仍在后端完成。

## 本地加载

1. 打开 `chrome://extensions`。
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择本目录。
4. 点击扩展图标，填写 `http://localhost:3000` 并保存。
5. 在同一个 Chrome 中登录抖音，刷新项目抓取页。

## 权限边界

- 固定访问 `https://*.douyin.com/*`，用于搜索和读取用户有权访问的视频详情。
- 项目网站权限是可选权限，只有用户在弹窗点击保存时才申请。
- 不读取浏览历史、Cookie、密码或其他网站数据。
- 后端只给每个抓取任务签发一次性令牌，不把 AI 密钥交给扩展。

## 调试

修改代码后在 `chrome://extensions` 点击本扩展的“重新加载”，然后刷新项目页面。纯解析逻辑可运行：

```bash
npm run test:extension
```
